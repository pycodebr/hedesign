Aviso com Desfazer

O aviso confirma o que acabou de acontecer, em uma frase. Quando a ação pode ser revertida ele traz o botão Desfazer e uma barra de contagem com os seis tons, que para enquanto o ponteiro ou o foco estiverem nele. Avisos são sempre escuros, nos dois temas, e ficam no canto de baixo, acima do campo de pedido.

Gaveta, folha e camada de detalhe

Três camadas, uma para cada tamanho de tarefa. A gaveta entra pela direita para algo que complementa a tela, como a atividade da IA ou um filtro longo. A folha é uma caixa central para uma decisão curta. A camada de detalhe cobre a tela inteira para abrir um item e, ao fechar, devolve a rolagem e o foco ao ponto exato. No celular as três sobem de baixo, e gaveta e folha fecham arrastando a alça.

Paleta de comandos

Ctrl K (ou Cmd K) abre a busca de qualquer lugar. Ela mistura itens, telas e ações, agrupados, e o último resultado é sempre entregar o texto digitado à IA. A aplicação registra as fontes.

HE.palette.register({ group: "Ir para", items: [ { label: "Planejamento", icon: "board", href: "/planejamento/" }, { label: "Resultados", icon: "chart", href: "/resultados/" } ] }); HE.palette.register({ group: "Itens", search: (q) => fetch("/api/busca?q=" + encodeURIComponent(q)).then((r) => r.json()) // cada item: { label, hint, icon, tone, img, href, onSelect } }); HE.shortcuts.add("Fila", ["A"], "Aprovar o item aberto");

Regras das camadas

  • Uma camada por vez. Esc fecha a de cima, o foco fica preso dentro dela e volta para quem abriu.
  • A página não rola por baixo e nada salta de lugar: a largura da barra de rolagem vira respiro.
  • Não use caixa de confirmação para ação reversível. Faça a ação e ofereça o Desfazer no aviso.
  • Folha só para decisões que cabem em uma tela de celular. Passou disso, é camada de detalhe ou página.
