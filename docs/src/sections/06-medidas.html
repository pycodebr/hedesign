Espaço

Escala de base 4. Dentro de um componente os saltos são de 4 e 8; entre blocos de uma tela, 24 e 32.

Forma

Tudo o que se clica é pílula: botões, chips, abas da barra, selos. Superfícies que guardam conteúdo usam raio de 14 ou 20 px. O raio pequeno fica para campos e itens de menu.

6px--he-r-xs
etiqueta, tecla
10px--he-r-sm
campo, item de menu
14px--he-r
cartão, aviso
20px--he-r-lg
painel, coluna, folha
999px--he-r-full
botão, chip, selo

Elevação

Quatro níveis. O que está parado na página tem só o contorno interno de 1 px. A sombra aparece quando algo responde ao ponteiro ou flutua sobre a tela.

Contornoinset 0 0 0 1px
painel parado
Nível 1--he-shadow-1
cartão, item ativo
Nível 2--he-shadow-2
cartão sob o ponteiro
Flutuante--he-shadow-pop
menu, paleta, gaveta
IA--he-shadow-ai
campo de pedido

Alvos de toque e larguras

  • Todo controle tem 40 px de altura no mínimo. O botão pequeno (32 px) volta para 40 px no celular.
  • Controles menores que isso ganham área invisível com ::after, como o "x" das etiquetas de contexto.
  • A página tem até 1320 px (.he-page), 860 px para leitura (.he-page--narrow) ou a largura toda (.he-page--full).
  • Os pontos de quebra são 1023 px (o menu lateral vira gaveta), 900 px (colunas viram pilha) e 760 px (modo celular: barra inferior, folhas que sobem de baixo).
