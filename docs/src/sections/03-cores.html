A paleta parte de um papel quente no tema claro e de um grafite levemente azulado no escuro. Cada token tem um papel, e o papel importa mais que o valor: troque o valor para adaptar a marca, mantenha o papel para o sistema continuar coerente. Clique em uma cor para copiar o nome do token.

Fundo e superfícies

Tinta

Cinco degraus de texto. --he-ink também é a cor do botão principal: no tema escuro ele vira claro, e o texto dele vira --he-bg.

Linhas, realce, destaque e estados

Regras de uso

  • Texto corrido usa --he-ink-2 ou --he-muted. --he-faint é o limite para texto pequeno e ainda passa de 4,5:1 sobre o fundo. --he-ghost nunca carrega informação.
  • O azul de destaque marca foco, link e seleção. O botão principal da tela é em tinta, nunca em azul.
  • Contorno de superfície é box-shadow: inset 0 0 0 1px var(--he-line), e não border: a medida da caixa não muda e o contorno acompanha o raio.
  • Nenhuma tela escreve cor fixa. Se um valor novo for necessário, ele entra como token nos dois temas.
